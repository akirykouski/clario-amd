# Clario demo script (one take, about 4 minutes)

Two browser windows side by side: patient app (phone width, port 8765) and clinic console (laptop width, port 8800; for the real run the public deploy, with Gemma 4 31B on AMD Token Factory). Italian UI on both. Persona "Giulia (IT)" already loaded, vault unlocked, 3 sample referti NOT yet imported. Import them in step 1, before sharing: with them the code-computed ranking puts SLE first, without them second (`backend/clario/data/demo/LABELS.md`). Loading the persona again replaces it, so a retake does not duplicate the diary. The English persona "Giulia (EN)" has the same structure (two hedged sentences, a negation, "my mother has lupus"); use the bracketed English lines and the English entry text of step 2. Use "No" when the app asks the next question, so no extra condition is confirmed.

Start command for the rehearsal without a GPU: `CLARIO_OFFLINE=1 CLARIO_PSEUDONYMIZE=1 CLARIO_DEMO_INSTANCE=1 CLARIO_CLINIC_URL=http://<clinic host>:8800` on the patient app. `CLARIO_CLINIC_URL` presets the address on the Share page (it travels in `GET /api/health`), so nobody types a URL on stage. Offline output comes from fixtures, so every number seen in that mode is a test number and is not quoted.

## Safety lines to have ready

- Emergency text ("non riesco a respirare") shows the notice first, saves the note.
- A dosing question ("posso aumentare la dose?") is answered with "ask your doctor or pharmacist", saved, and no model call is made.
- Brief items that sound like a diagnosis or a dose are dropped in code before the clinician sees them.
- A brief line that names a term none of its cited entries confirms is shown in amber on its line in "Modifica e firma"; the clinician removes it, fixes it or taps "Tieni comunque" before "Firma" turns on. Kept unchanged, it never reaches the patient copy.
- The draft PDF is watermarked "Bozza IA, non rivista"; only the signed PDF carries the clinician's name.
- The dosing interceptor lives in `backend/clario/safety.py` (`check_entry`).

## Reset between takes

Stop both servers by PID, delete the two data dirs, start again. Setup vault, "Dati dimostrativi", "Giulia (IT)", "Carica il diario". Loading it again replaces the earlier demo diary and referti. The language follows the browser; the switcher is in both headers.
