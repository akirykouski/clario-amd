# Clario demo script (one take, 3 minutes)

Two browser windows side by side: patient app (phone width, port 8765) and clinic console (laptop width, port 8800, on the AMD server for the real run). Italian UI on both. Persona "Giulia (IT)" already loaded, vault unlocked, 3 sample referti NOT yet imported. The English persona "Giulia (EN)" has the same structure (two hedged sentences, a negation, "my mother has lupus"); use the bracketed English lines and the English entry text of step 2. Use "No" when the app asks the next question, so no extra condition is confirmed.

Start command for the rehearsal without a GPU: `CLARIO_OFFLINE=1 CLARIO_PSEUDONYMIZE=1 CLARIO_DEMO_INSTANCE=1 CLARIO_CLINIC_URL=http://<clinic host>:8800` on the patient app. `CLARIO_CLINIC_URL` presets the address on the Share page (it travels in `GET /api/health`), so nobody types a URL on stage. Offline output comes from fixtures, so every number seen in that mode is a test number and is not quoted.

## Where the AMD numbers come from

Never type a number that is not in a file.

| Number | Source | Status |
|---|---|---|
| Pages per second (step 1) | Shown by the app from the batch it just ran (`/api/documents/batch/{id}/events`). For the slide: `backend/scripts/make_referti.py` makes a 200 page batch, run it on the droplet, keep the screenshot | Real run on the droplet NOT done. The 3-page offline run is a fixture speed |
| GPU name and load | `GET /api/system/gpu` (amd-smi on the droplet or the sidecar in `backend/clario/gpu.py`) | amd-smi JSON shape is from AMD docs, unverified on hardware |
| Tokens/s and latency (step 7) | Per call, from the usage field of the model response, shown in the brief panel. Aggregated runs: `bench/results/*.json` via `GET /api/bench` | Not run yet |
| Extraction quality (F1, HPO id accuracy, JSON validity, base vs LoRA) | `eval/results/extraction_*.json` (fields n, dataset, model, backend, date), rendered in `eval/RESULTS.md` | Only dry-run and offline files exist until the droplet run |
| Review-curve numbers | `eval/review_curve.py` over a results file | Same |
| Pseudonymisation miss rate (step 5) | `eval/results/pii_leak.json`, test half: 10.8% held out; 5.8% after fixes chosen by reading test failures, of identifiers, n = 712, synthetic, rules only | Measured (CPU, no model). Optimistic: written by the redactor's author |
| Minutes saved per visit (pilot metric) | `GET /api/clinic/metrics`: AI lines kept, edited, removed and time to sign per brief | Counter exists. No pilot has run, so no figure is quoted |

If a result file is missing, the slide says "measured on the droplet, see repo" and shows no figure.

## Safety lines to have ready

- Emergency text ("non riesco a respirare") shows the notice first, saves the note.
- A dosing question ("posso aumentare la dose?") is answered with "ask your doctor or pharmacist", saved, and no model call is made.
- Brief items that sound like a diagnosis or a dose are dropped in code before the clinician sees them.
- A brief line that names a term none of its cited entries confirms is shown as a warning in "Modifica e firma"; the clinician deletes or fixes it before signing. Kept unchanged, it never reaches the patient copy.
- The draft PDF is watermarked "Bozza IA, non rivista"; only the signed PDF carries the clinician's name.
- The dosing interceptor lives in `backend/clario/safety.py` (`check_entry`).

## Reset between takes

Stop both servers by PID, delete the two data dirs, start again. Setup vault, "Dati dimostrativi", "Giulia (IT)", "Carica il diario". The language follows the browser; the switcher is in both headers.
